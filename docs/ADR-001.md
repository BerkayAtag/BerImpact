# ADR-001 — On-premises modular monolith

Status: accepted, 2026-11-05. Empty workspace; .NET 10.0.403 SDK, 10.0.14 runtime, Node 24 and both Docker engines available.

Use .NET 10 LTS, ASP.NET Core, EF Core 10 / Npgsql 10, PostgreSQL 17, React/TypeScript/Vite. Context7 verified ASP.NET cookie/antiforgery patterns, Npgsql concurrency and Vite Node compatibility. Use separate API and worker processes with PostgreSQL-backed bounded jobs. No Redis, external AI, CDN, telemetry exporter or cloud runtime dependency.

Domain and Application contain deterministic logic; Infrastructure owns EF persistence and job execution; SDK defines read-only connector contracts. Connectors are compiled, explicitly registered adapters. External integrations stay disabled until explicitly configured. Observe mode is enforced server-side; no infrastructure-write interface exists in this increment.

Local Identity accounts use salted Identity password hashes, lockout, HttpOnly cookies, antiforgery on every mutation, roles, and append-only audited operations. Initial administrator is provisioned through local CLI, never public registration. PostgreSQL triggers reject audit updates/deletes; database superusers remain a documented trust boundary. TLS is required in production; loopback development has an explicitly separate configuration.

Stable identity is (source namespace, source object ID); hostnames never merge identities. Cross-source reconciliation requires explicit strong-key evidence in a later phase. Imported records retain provenance, evidence state, timestamp and test/live classification. Risk is an index, not probability; unknown factors yield a range and a review gate rather than invented certainty. Each analysis stores immutable input, ruleset and results.

Initial scope: executable foundation plus vertical inventory/change/analysis/simulation/report/governance workflow. Advanced GPO semantics, all vendor integrations, orchestration and enterprise-scale certification remain separate milestones. Limits reject oversized analyses explicitly, never silently truncate. Development tests use isolated PostgreSQL databases, never enterprise systems.
